    變數：會記東西的盒子 📦

    電腦要計算，就得先把數字「記」起來。變數就是用來記數字的盒子。

    什麼是變數？

    變數像是貼著名字標籤的盒子：盒子有名字（例如 x）、有種類（只能放某種東西）、裡面放著數值。
    x
    10
    y
    40
    int x=10, y=40; 的意思：做出兩個放整數的盒子，名字叫 x 和 y，分別放進 10 和 40。

    資料型態：盒子的種類

    型態放什麼例子
    int整數（沒有小數點）10、-3、0
    float小數（浮點數）3.14、-0.5
    char一個字元'A'、'7'（用單引號）
    📝 取名字的規則 只能用英文字母、數字、底線 _；不能用數字開頭；不能和 int、return 這類保留字相同；大小寫視為不同（Sum ≠ sum）。

    = 不是「等於」，是「放進去」

    這是初學者最容易搞混、也最重要的觀念。

    數學：x = x + 1 是一個不可能成立的等式。
    C++：x = x + 1 是一個動作：先算右邊，再把結果放進左邊的盒子。
    所以 sum = sum + i 的意思是：新的 sum = 舊的 sum + i。

    逐步執行看看：sum 從 18 變成幾？

y = x;

    第 6 課

    標頭檔 #include：向「工具箱」借工具 🧰

    每個程式最前面都有 #include <iostream>，它到底是什麼？不寫會怎樣？

    為什麼需要標頭檔？

    C++ 語言本身只有「最基本」的功能。像印字（cout）、開根號（sqrt）、找最大值（max）這些常用功能，被分類收進不同的「工具箱」，這些工具箱就叫標頭檔（header file）。
    要用哪個工具，就用 #include 把那個工具箱「借進來」。不借，電腦就找不到工具。
    📌 寫法規則 ① 一定要有 #　② 標頭檔名稱放在 < > 尖括號裡　③ 結尾不加分號　④ 寫在整個程式的最前面（在 main 之前）。
    名稱不用 .h：C++ 寫 <cmath>（C 語言舊寫法是 <math.h>）。

    常用標頭檔一覽

    標頭檔提供的工具例子
    <iostream>輸入輸出cout、cin、endl
    <cmath>數學函式sqrt(x) 開根號、pow(a,b) a 的 b 次方、abs(x) 絕對值、floor/ceil/round
    <algorithm>演算法工具max(a,b)、min(a,b)
    <iomanip>控制輸出格式setprecision(n) 控制小數位數
    <string>文字處理string 型態
    ⚠ 還有一個「萬用工具箱」 #include <bits/stdc++.h> 會一次借進幾乎所有工具箱，比賽時很常見。但它不是標準寫法、有些電腦編譯不過，也讓你不知道自己到底用了什麼。學習階段請需要什麼就借什麼。
    進階：尖括號 < > 和雙引號 " " 有什麼不同？

    #include <名稱>：到「系統提供」的地方找。#include "名稱.h"：先到「你自己的資料夾」找 —— 以後你會自己寫標頭檔來整理大型程式。

    ① 親手借借看

    🔎 觀察刪掉 #include <cmath> 之後，錯誤訊息說了什麼？它會告訴你該借哪個標頭檔！記住這種提示，以後遇到「xxx 找不到」時先想：是不是少借了工具箱？
    想用 max(a,b) 找兩數中較大的，應該加上哪個標頭檔？
    1. #include <iostream>
    2. #include <algorithm>
    3. #include <string>
    max 和 min 收在 <algorithm>。
    下面哪一行寫法正確？
    1. include <cmath>
    2. #include <cmath>;
    3. #include <cmath>
    4. #include cmath
    要有 #、要有尖括號、結尾不加分號。

    比較與邏輯：讓電腦回答「對 / 錯」

    電腦能做決定的基礎：判斷一件事「成立」還是「不成立」。

    比較運算子

    符號意思符號意思
    ==等於!=不等於
    >大於<小於
    >=大於或等於<=小於或等於

    比較的結果只有兩種：成立 = 1（真, true）、不成立 = 0（假, false）。

    ⚠ 一個 = 和兩個 == 完全不同！ x = 5：把 5 放進 x（動作）。x == 5：問 x 是不是 5（問題）。

    邏輯運算子：把多個條件組合起來

    🔬 真值表：按按看 A、B

    經典錯誤：連續比較

    數學可以寫 80 ≤ s ≤ 89，但 C++ 不是這個意思（可以編譯，答案卻不對）！拖拉滑桿，看看兩種寫法的結果：

    🔬 80 分到 89 分之間？

    把 s 改成 95 再執行：第一行還是 1（成立），顯然錯了！

    (5>3) && (2>4) 的結果是？
    1. 1（成立）
    2. 0（不成立）
    && 是「而且」，兩邊都要成立才成立。5>3 成立，但 2>4 不成立，所以整體不成立 = 0。
    想判斷「x 在 10 到 20 之間」，正確寫法是？
    1. (x>=10) && (x<=20)
    2. 10<=x<=20
    3. (x>=10) || (x<=20)
    要「而且」→ &&。用 ||（或者）的話，任何數字都會成立。

    if：讓程式學會「做決定」

    之前的程式都是從頭跑到尾。現在，程式可以依情況走不同的路了。

    🌂 生活中的 if：如果下雨，就帶傘；否則，就戴帽子。
    if ( 條件 ){
    條件「成立」時才做這裡
}
else{
    條件「不成立」時做這裡
}

    ① 只有 if

    輸入 75 和 59 各試一次。59 的時候為什麼什麼都沒印？

    ② 加上 else

    📌 格式提醒if 的條件要放在 小括號 裡；要做的事放在 大括號 { } 裡（只有一行時可省略大括號，但建議保留）。if 後面不要加分號。

    ③ 奇數還是偶數？

    用到第 5 課的 %：偶數除以 2 餘 0。

    int n=7;，if(n%2==0) 的條件成立嗎？
    1. 成立，因為 7 是整數
    2. 成立，因為 7%2 是 1
    3. 不成立，因為 7%2 是 1，不等於 0
    7 ÷ 2 = 3 餘 1，所以 7%2==0 不成立，會走 else → 奇數。

    找三個數字中的最大值 👑

    把前面學的全部組合起來：輸入、變數、if、指定。

    「擂台」演算法

    ① 先讓第一個人當擂台主（max = score1）
    ② 第二個人上台挑戰：比擂台主大 → 取代他（if(max<score2) max=score2;）

    想判斷 s 是否在 80 到 89 之間，哪個正確？
    1. 80<=s<=89
    2. s>=80 && s<=89
    3. s>=80 || s<=89
    C++ 不能連寫，要用 && 把兩個條件接起來。
    交換 a 和 b 的正確順序是？
    1. a=b; b=a;
    2. t=a; b=t; a=b;
    3. t=a; a=b; b=t;
    先備份 a，再讓 a 變成 b，最後把備份放進 b。
    int s=75;
if(s>=90) cout<<"A";
else if(s>=80) cout<<"B";
else if(s>=70) cout<<"C";
else cout<<"D";
    印出？
    1. C
    2. C 和 D
    3. D
    4. 什麼都沒有
    75 先通過 ≥70，印出 C，之後略過 else。
    if(x=3) 這種寫法的問題是？
    1. 沒有問題
    2. 應該寫成 if(x==3);
    3. 用了 =（放進去），應該用 ==（比較）
    這是最常見的 bug 之一。= 會把 x 改成 3，而且條件永遠成立。

    🧰 錯誤訊息速查表

    訊息關鍵字通常是因為…
    少了分號 ;每個敘述結尾都要 ;
    還沒有宣告變數沒先用 int x; 做出來，或名字打錯
    少了 <<cout 的每個項目中間都要有 <<
    大括號不成對{ 和 } 數量要相同
    全形符號用了中文輸入法的 ； （ ） ，，程式只認半形
    (警告) 整數除法想要小數結果時，要有一邊是小數
    (警告) if 裡的 =比較要用 ==
